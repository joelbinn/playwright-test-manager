# Inbäddad Playwright Trace Viewer i applikationen

Vi har valt att låta backend servera Playwright Trace Viewer lokalt så att traces kan inspekteras direkt i en integrerad vy i applikationens gränssnitt vid testfel. Detta bevarar användarens kontext och gör att granskning av körningsspår och aktivering av Healer sker i samma sammanhängande arbetsyta utan att användaren behöver lämna gränssnittet.
