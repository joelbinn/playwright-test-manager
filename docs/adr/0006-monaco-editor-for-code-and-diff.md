# Monaco Editor för kodredigering, Markdown och visuell diff

Vi har valt att använda Monaco Editor som redigerings- och granskningskomponent i frontend. Monaco tillhandahåller färdiga, högpresterande mekanismer för TypeScript-syntax, Markdown, och framförallt inbyggd side-by-side och inline kod-diffing, vilket matchar arbetsflödet för granskning av agentgenererad kod.
