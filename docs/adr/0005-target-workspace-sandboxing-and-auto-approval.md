# Sandlåda och automatiserat godkännande inom projektkatalogen

Vi har valt att låta ACP-klienten i backend automatiskt godkänna filoperationer inom målarbetsytans rotkatalog men strikt förbjuda all åtkomst och exekvering utanför denna katalog. Detta eliminerar friktionen med återkommande manuella behörighetsdialoger för varje enskild filläsning eller sökning som agenten utför under generering eller läkning, samtidigt som användarens omgivande filsystem skyddas.
